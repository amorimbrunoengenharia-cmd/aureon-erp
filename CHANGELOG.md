# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-12-08

### Added
- **Sistema de Simulação Completo**: 46 cenários automatizados (100% cobertura)
- **Documentação Consolidada**: README unificado + estrutura docs/
- **Modo Simulação**: Sandbox com IA generativa
- **EventBus**: Arquitetura event-driven com trace_id
- **IA Integrada**: OpenAI GPT-4o-mini para insights
- **Integrações**: Mercado Livre + Alibaba (RapidAPI)
- **9 Módulos**: Dashboard, Estoque, Vendas, CRM, Comunicação, Análises, Metas, Compras, Configurações

### Changed
- **Documentação**: Consolidados 17 arquivos MD → estrutura unificada
- **README.md**: Agora inclui quickstart, scripts, troubleshooting completo
- **.env.example**: Adicionadas todas variáveis de ambiente necessárias

### Fixed
- **Segurança**: Removida chave de API OpenAI do histórico Git
- **Links**: Atualizados para nova estrutura de documentação

## [1.0.0] - 2025-12-05

### Added
- Sistema ERP básico com React + Vite
- Dashboard com KPIs
- Gestão de estoque
- Módulo de vendas
- CRM básico
- LocalStorage como banco de dados
