## 🎯 Sobre o Projeto

AUREON ERP é um sistema completo de gestão empresarial com:

- ✅ **9 Módulos Integrados**: Dashboard, Estoque, Vendas, CRM, Comunicação, Análises, Metas, Compras, Configurações
- 🤖 **IA Integrada**: OpenAI GPT-4o-mini para análises preditivas
- 🎮 **Modo Simulação**: 46 cenários de teste automatizados
- 🔗 **Integrações**: Mercado Livre e Alibaba
- 🐳 **Docker Ready**: Deploy simplificado
- 🧪 **Testes E2E**: Playwright com coverage completo

## 🚀 Quick Start

```bash
# 1. Clone o repositório
git clone https://github.com/amorimbrunoengenharia-cmd/aureon-erp.git

# 2. Entre no diretório
cd aureon-erp/aureon-os

# 3. Instale dependências
npm install

# 4. Configure ambiente
cp .env.example .env

# 5. Execute
npm run dev
```

Acesse: `http://localhost:5173`

**Login**: `admin` / `admin123`
